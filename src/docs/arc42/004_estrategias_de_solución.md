**Decisión 1: Web app Angular**

- Problema: Necetiamos un producto pequelo con las herrmientas necesarias para un consultorio pequeño
- Solución: Web App Angular, se selcciono angular debido al conocimiento previo

**Decisión 1: Backend Java**

- Problema: Necetiamos un producto pequelo con las herrmientas necesarias para un consultorio pequeño y rapidez en la contrcucción
- Solución: Se selcciono Java debido al conocimiento previo, y es un lenguaje robusto

**Stack tecnológico:**

- Java (Rapidez en desarrollo por conocimeinto previo)
- Angular (Rapidez en desarrollo por conocimeinto previo)
- PSQL (Base de datos libre y sobre todo necesitamos base de datos relacional)
- DCM4CHEE (Herrmienta free para la construción de pacs, bastante robusto)
- OHIF (Visualizador de uso libre bastante robusto)
